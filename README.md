# Student's Task Manager

A simple Task Manager application built using HTML, CSS, and JavaScript.

## About the Project

This project allows users to add and manage their daily tasks. Users can enter a task using the input field and add it to the task list dynamically.

Each task contains:

- A checkbox to mark the task as completed
- A task label displaying the task name
- A delete icon to remove the task

When a user checks the checkbox, the task text gets a strike-through effect to indicate that the task is completed.

The application dynamically creates HTML elements using JavaScript DOM manipulation.

## Features

- Add tasks dynamically
- Mark tasks as completed
- Strike through completed tasks
- Delete tasks
- Dynamically generate checkboxes and labels
- Assign unique IDs to tasks
